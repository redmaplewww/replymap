# 使用手册

## 激活条件

回答超过约 900 个非空白字符、包含至少五个有意义的段落或标题、至少四个步骤，或包含多阶段计划、决策树、系统架构时，适合生成 ReplyMap。短答、代码专用答复和明确要求不画图时跳过。

## 信息抽取

优先抽取目标、参与者、证据、操作、状态变化、决策、输出、风险和后续动作。复杂回答保留 8–12 个真实节点；不要把所有内容压成空泛标签。

## 配色

- 靛蓝：目标或根节点；
- 蓝、紫、青绿：过程与证据；
- 琥珀：决策或分支；
- 绿色、青色：结果与输出；
- 珊瑚、红色：风险、限制或未解决状态。

为 Mermaid 使用 `classDef`，为 HTML/SVG 使用同一组色彩令牌。颜色必须和文字、形状或图例一起表达语义。

## 布局与降级

解释、计划和因果关系优先 `flowchart TD`；系统流水线优先 `flowchart LR`。默认不超过 12 个节点；复杂回答使用分支、证据泳道和决策点。Mermaid 不可用时，保留相同 ID、顺序和关系，以缩进式阅读地图呈现。
